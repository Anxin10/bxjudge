# 軌跡交接修正計畫

**Goal:** 修正 ByteTrack 在同格或少量重疊影格換 ID，造成原本可證實的陀螺軌跡無法接續。
**Architecture:** 沿用既有 ByteTrack 與 prepare_launch_tracks 的互相唯一接續。增加嚴格邊界重疊檢查：起訖時間必須向前、重疊每格都有兩方原始觀測且框 IoU 達標，速度/尺度/預測位置沿用既有守門，兩方既有side矛盾則拒絕。共用影格保留較早軌跡原始觀測，另存所有被取代觀測與成員ID，永不插補影格或推測物理分離。
**Tech Stack:** 現有 Python / supervision.box_iou_batch / pytest，無新增依賴。

## Constraints

沿用 feat/local-judge，不新開分支；來源影片、原始人工提交、先前結果不修改；設定值在 YAML；接續仍強制人工覆核，不能直接宣稱身分問題全面解決。

## Review focus

重疊真實兩顆不能因單格碰撞而混接；鏈式合併不得重複frame；side保護不得猜新side；重複觀測須可追溯；所有新合併須維持覆核，不把軌跡減少當正確率。
