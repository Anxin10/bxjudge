# 動態校準與裁判證據整合設計 — 2026-10-25

使用者已以兩則標註授權繼續實作先前提出的順序；保留 feat/local-judge，同一工作目錄，禁止新增分支／工作樹。採 inline 執行，無重複方向確認。

目標：持續位移後可提出並驗證新基準，將逐格幾何接入落點／出界分析，並處理掛在發射器的前置觀測及可唯一接續的追蹤碎片。保持原始影片、已覆核結果、原始盤面晃動證據與完整wall time。

方法：
1. 小位移沿用現有固定快照錨點的ORB/RANSAC/ECC；短暫失敗不補值。持續失敗才定時用既有較廣範圍estimate_alignment向原始快照重新定位；候選必須高分且連續確認幾何一致，採用時記錄新段，所有矩陣仍映射原快照座標到當前影格，禁止累積漂移。
2. 重新定位不是自動認可所有場景；每個候選段保留分數、確認影格、矩陣、原始幀及失敗區間。無法驗證仍未知並需覆核。預覽與核心共用同一tracker；設定明確保存在yaml，不改既有小位移門檻。
3. 核心先以raw影格偵測／追蹤，再以每格矩陣逆變換把實際觀測轉至基準盤面座標，無法對位的觀測不當有效幾何。原始軌跡輸出保持影格座標，供影像裁切與回放；裁判採基準座標，記錄座標語意。原始stadium_motion仍對本片first-second frame量測，不使用穩定化圖像。
4. 只有發射器身體實際觀測支援的掛載→分離序列可排除前置held-bey觀測；不以落地或後來的終結結果倒推發射，不延長既有3秒期限。缺乏證據要明確標示未知。追蹤碎片只允許短缺口、位置／速度相容、前後唯一候選的接續，不插點，不跨越模糊歧義。
5. 以明確 --dynamic-calibration 設定啟用核心新流程，原靜態模式保留作為可比較基準（不是舊資料相容fallback）。新試跑使用新out，不動已覆核pilot，不轉移時間不匹配的人工真值。

替代方案：僅放寬門檻會接受錯位，排除；每影格全域配準成本高且遮擋不穩，改為持續拒絕後稀疏重新定位；全影片畫面穩定化會改變觸盤證據及裁切座標，改為只對裁判觀測變換。

驗收：遮擋失敗不補矩陣；持續平移／旋轉能建立穩定新段並回復；同一實際幾何移動前後落點／出界相同；掛載等待不消耗分離後3秒窗；歧義碎片拒絕接續；舊人工結果雜湊不變；獨立審查與小批完整wall time、覆核率、無外推的準確率欄位。

限制：已知舊全域校準4個xfail不能當可靠承諾；新增重新定位須較嚴格候選驗證並保留review。無逐格X/B真值，任何提升不能憑ID數量認定。實際需要人工真值的驗收會明確標示未完成，不假造通過。
